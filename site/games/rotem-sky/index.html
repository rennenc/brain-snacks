How it works

Changing the listener takes effect the next time the game is opened.

Right on the first try earns 3 ★, second try 2 ★, after that 1 ★. Pressing “Hear it” first also makes it 1 ★. A wrong answer is only counted when the game clearly hears a different sound from the list, so chatting in the room is ignored. After a wrong answer the microphone pauses for a moment, so fast guessing doesn't pay. After two misses the bird says the sound for her.

If the game didn't hear a correct answer, press Enter or tap the small ✓ in the corner.
